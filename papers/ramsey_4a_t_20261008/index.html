Common Independent Sets in a Fixed Number of K4-Free Graphs

Research manuscript · Revised 8 October 2026 · Preliminary and not peer reviewed

LaTeX manuscript Detailed overview and proof outline GitHub repository files

Overview

This manuscript studies multicolour off-diagonal Ramsey numbers r(4,...,4,t), where the entry 4 occurs a fixed number a of times. The equivalent graph-theoretic problem is to construct several K4-free graphs on a common vertex set whose union has a small independence number. For a = 2, this is the three-colour Ramsey problem r(4,4,t).

Main result

The manuscript claims that for every fixed integer a ≥ 1 and every ε > 0, there is a positive constant ca,ε such that for all sufficiently large t,

r(4, …, 4, t) ≥ ca,ε t2a+1 / (log t)2a+ε.

Combined with the upper bound of He and Wigderson, the claimed asymptotic form for a fixed number of small colour classes is

r(4, …, 4, t) = t2a+1 / (log t)2a+o(1).

In particular, the special cases include r(4,4,t) = t5 / (log t)4+o(1) and r(4,4,4,t) = t7 / (log t)6+o(1). The number a is fixed as t tends to infinity.

Method and relation to previous work

The construction is based on Bradač's ordered flag digraph D*(3,q) and associated K4-free graphs. A one-colour entropy estimate controls forward independent flag tuples in products of small coordinate domains.

A cited theorem from OpenAI's formalized SharpLogRamsey source provides a compression step under an orthogonal-rectangle occupancy condition. The manuscript uses rectangle peeling and an entropy argument to remove this condition. Projection-closed covering families then allow the compression to be iterated one colour at a time without increasing the covering complexity of the other colours.

External theorem and manuscript status

This is an unrefereed preliminary manuscript. Independent verification is pending, including the interface between the cited Lean theorem and its finite-cover consequence. The external compression theorem is used as a black box; the manuscript does not independently prove it.

The formal input is OpenAI's eventually_selected_step specialized to dimension four, with related entropy-cost estimates. The matching upper-bound exponent is due to He and Wigderson. This manuscript was produced by GPT-6 under the author's guidance.
