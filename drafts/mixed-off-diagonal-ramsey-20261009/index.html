Common Independent Sets in Ks1-Free, …, Ksk-Free Graphs

Research draft · source revised October 8, 2026 · preliminary and unrefereed

Read the LaTeX manuscript · Detailed overview, proof outline and keywords

Overview

The manuscript considers multicolour off-diagonal Ramsey numbers r(s1,…,sk,t), with a fixed number of colours and fixed forbidden clique sizes si ≥ 3. Equivalently, it studies common independent sets in a family of graphs where the i-th graph is Ksi-free.

Main result

Put S = ∑i=1k(si − 2). For fixed parameters and every ε > 0, the draft claims a constant c > 0 with

r(s1,…,sk,t) ≥ c tS+1/(log t)S+ε.

Combining with the cited He–Wigderson upper bound gives the claimed logarithmic-exponent asymptotic

r(s1,…,sk,t) = tS+1/(log t)S+o(1).

Special cases include r(3,4,t) and r(4,4,t). The parameter k and the clique sizes are fixed as t tends to infinity.

Methods and previous work

The argument uses Bradač's ordered projective flag construction, entropy bounds on forward independent tuples, and an external single-colour compression theorem from OpenAI's formal SharpLogRamsey source. Rectangle peeling removes an orthogonal-rectangle occupancy restriction for the desired covering reduction. Projection-closed covering families support a multicolour induction. Colours forbidding triangles are handled using an independent-set counting theorem of Andrades, Campos and Morris.
